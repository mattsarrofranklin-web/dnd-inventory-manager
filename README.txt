D&D INVENTORY MANAGER 0.9.3 - PWA PACKAGE

Upload the contents of this folder to the root of the GitHub repository.
The index.html file must be at the repository root.

The website must be served over HTTPS to install as a PWA.
Before moving from the old local-file version, export a JSON backup.
The hosted site has separate browser storage. Import the JSON backup after opening it.
The app shell is cached for offline use after the first successful visit.
